# ABTalks — AI Usage Log

## Project
ABTalks is a 60-day coding challenge platform designed for students to build consistently, track their progress, and make their learning visible through GitHub and LinkedIn proof.

## AI Assistance Used

AI assistance was used throughout the development process for ideation, UI/UX planning, React implementation, debugging, functionality, and visual refinement.

### Initial Product & UI/UX Prompt
Designed a premium, modern student-focused 60-day coding challenge platform called ABTalks. The experience should feel motivational, polished and production-ready, with glassmorphism, dark visuals, progress tracking, streaks, achievements, challenge cards and responsive mobile UX.

### Landing Page
Used AI assistance to structure and refine:
- Hero section
- 60-day challenge messaging
- Call-to-action
- Trust/proof sections
- Responsive layout
- Premium dark visual design

### Dashboard
AI assistance was used to implement and refine:
- Current streak
- Challenge completion count
- 60-day progress
- Progress ring
- Current challenge card
- GitHub-style activity heatmap
- GitHub and LinkedIn proof sections
- Achievement milestones
- Responsive navigation

### Challenge Day
AI assistance was used to implement:
- Day-based challenge routing
- Day 12 / Day 13 progression
- Challenge objectives
- Acceptance checklist
- GitHub proof URL
- LinkedIn proof URL
- URL validation
- Completion state
- LocalStorage-based progress persistence
- Sequential challenge unlocking

### Debugging
AI assistance was used to troubleshoot:
- React rendering issues
- CSS styling conflicts
- Vite development issues
- React Router navigation
- LocalStorage synchronization
- Git/GitHub repository setup
- Deployment workflow

### Final Refinement
AI assistance was used to improve:
- Glassmorphism styling
- Responsive layouts
- Cards and spacing
- Progress visualization
- User feedback states
- Challenge completion experience
- Overall visual polish

## Human Contribution

The project concept, product direction, challenge structure, design decisions, testing, implementation environment, repository management, deployment and final submission were handled by the project team.

AI was used as a development and design assistant, while the final project was assembled, tested and deployed by the team.
